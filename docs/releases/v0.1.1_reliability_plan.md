### 1.2 Failure 1 — stale gitignore assertion

**Exact assertion (failing):**

```python
assert "test_cases/**/preprocess/" in ignored_patterns
```

**Observed `.gitignore` (committed):**

```text
/test_cases/
```

- Obsolete pattern `test_cases/**/preprocess/` is **absent**.

**Root cause:** Stale test expectation vs intentional ignore policy. Not a packaging regression.

**Lab-artifact dependence:** None.

**Minimum correction:** Update the test to assert `/test_cases/` (and keep the other ignore assertions that still match). Do **not** revert `.gitignore` to the narrower pattern.

**Acceptance:** `test_gitignore.py` passes on a clean clone without local sessions.

**Fix landed:** test asserts `/test_cases/`.

### 1.3 Failures 2–3 — E-session “no published review” assumptions

**Exact failing tail (both tests), after a valid `assert_no_upstream_writes(...)`:**

```python
# Opening must not create a review draft.
assert not (SESSION / "behavioral_review").exists() or not any(
    (SESSION / "behavioral_review").glob("behavioral_review__*")
)
```

**Observed on this workstation:**

- E-session present: `test_cases/E_full_session_integration`
- Published review present: `behavioral_review__20261029T194225` (lab-accepted S10)
- Predicate `no published review runs` → **False** → assertion fails

**Root cause:** Invalid test assumption after successful laboratory S10 publication. Comment intent (“opening must not create a review draft”) is correct; the predicate incorrectly requires the session to have **zero** published `behavioral_review__*` directories. Upstream immutability helpers already ran successfully before the tail assert — this is **lab-state pollution from a legitimate publish**, not a new write-path regression.

**Lab-artifact dependence:**

| Environment | Module gate | Tail assert |
| --- | --- | --- |
| No E-session / ineligible package | `pytest.mark.skipif` → **skip** | N/A |
| E-session eligible, no published review | Runs | Passes |
| E-session eligible, published review (post lab accept) | Runs | **Fails** |

**Do not:** delete legitimate review runs to green the suite; weaken `assert_no_upstream_writes` / production publication validation.

**Minimum correction (preferred):**

1. Snapshot `behavioral_review__*` run ids (and optionally mtimes/digests) **before** inspection seeks.
2. Perform seeks / window reads.
3. Keep `assert_no_upstream_writes(...)` unchanged (S8/S9/video immutability).
4. Assert **no new** review run directories appeared (opening inspection did not create a draft/publish).
5. Optionally assert existing published run fingerprints unchanged.

Alternative (weaker): skip the “empty review tree” check when any published review already exists, while still asserting no new drafts. Prefer the snapshot approach so the original intent stays enforced.

**Sprint 3+ E-session tests** already combine `assert_no_upstream_writes` with intentional review creation and do **not** use this empty-tree assert — only Sprint 1/2 read-only smokes are wrong.

**Clean-machine behavior:** Without E-session data, these modules skip with an explicit reason. That is appropriate; do not require E-session on CI/fresh clones.

**Fix landed:** both Sprint 1/2 tests snapshot run ids before read-only ops and assert set equality afterward.

### 3.2 Automated integration (smallest practical) — **deferred**

**Assessment:** Existing fixtures are stage-local stubs:

| Fixture area | What it builds | Gap for S1→S10 chain |
| --- | --- | --- |
| `tests/blob_features` synthetic S1 | Tiny prepared sync / S1 trees | Does not feed real S2–S4 digests |
| `tests/behavioral_arbitration/_fixtures.py` | Linked fake S6+S7 for S8 | Skips full S4/S5 joint validation |
| `tests/results_packaging/_fixtures.py` | Fake eligible S8 → S9 | Not produced by upstream runners |
| `tests/behavioral_review/_fixtures.py` | Mini S9 packages for S10 | Starts at packaging boundary |

A truthful automated chain that asserts cross-stage eligibility, shared sync digests, source identities, discovery classification, and automated-vs-reviewed separation would need **new multi-stage fixture infrastructure** (estimated **1–2 engineering days**) to mint jointly valid S1–S10 artifact trees without calling GPU SLEAP or claiming biological validity.

**Decision for v0.1.1:** **Defer** the synthetic S1→S10 pytest. Rely on (1) existing per-stage contract tests, (2) corrected E-session read-only smokes when lab data present, and (3) the interactive fresh short-clip checklist. Do not ship a half-chain that pretends to cover S1→S10.
