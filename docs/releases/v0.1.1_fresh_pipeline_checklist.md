## 3. Fresh vs cached rules

- **Fresh:** stage runner executed in this smoke; new run directory created under the session.
- **Cached:** reused a prior completed run without re-executing. Allowed only if labeled; **does not** satisfy the v0.1.1 tagging bar for that stage.
- Reusing `test_cases/E_full_session_integration` is **cached scale evidence**, not this checklist.

**This execution:** all S1–S10 rows above are **Fresh** on `F_v011_fresh_short_smoke`. E-session was not reused.
