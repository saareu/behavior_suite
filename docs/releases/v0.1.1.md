## Doctor advisories (nonblocking)

`behavior-suite doctor` still **hard-gates** only on FFmpeg capability (modern Stage A timestamp contract).

After the FFmpeg summary it prints **nonblocking** advisories for:

- SLEAP-NN **0.3.x** availability (`probe_sleap_nn_runtime`)
- S7 Python runtime dependencies
- Persisted/suggested S7 model-registry discovery

Missing optional inference tooling must **not** block GUI launch. Stage readiness remains enforced at S2 preflight / S7 Run.
